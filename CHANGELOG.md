# Changelog

## v0.7.1 (2026-06-02)

### Добавлено
- Операторы `%`, `%=`, `^`, `^=`
- Рекурсивный сбор полей (`_collect_fields`) — поля из вложенных `if`/`while`/`for`
- Локальные переменные с авто-типом (`int dx = ...`)
- Инлайн-методы в `.h` файлах (всегда с телами)
- `_local_vars` для отслеживания объявленных переменных
- Тесты на `%`, `^`, `%=`, `^=`

### Исправлено
- `if` внутри методов — правильные отступы и парсинг тела
- `FunCall` в выражениях (`random()`, `sqrt()`)
- `_parse_primary` — вызов методов через `:` убран из выражений
- `time` → `gs_time` для избежания конфликта с системным
- `drop`, `collides` — поля корректно собираются из вложенных инструкций
- `compile_header` — `filepath` определён до использования
- Поля из `if`/`elif`/`else` корректно собираются

### Примеры
- `clock.gs` — убраны конфликтные `time()` и `delay()`
- `calculator.gs`, `rng.gs`, `aabb.gs` — добавлены поля

### Изменено
- Весь код документирован (tokens, lexer, ast_nodes, parser, codegen, compiler)
- `main()` переписан — чистая обработка аргументов
- `_generate_class` объединяет `_generate_class_def` и `_generate_class_decl`
- Примеры обновлены (`entity.gs`, `system.gs`, `hero.gs`, `__main__.gs`)

## v0.7.0 (2026-06-01)

### Добавлено
- Сеть: HTTP-запросы (`http_get`, `http_post`) через curl
- Сокеты: `socket_connect`, `socket_send`, `socket_recv`
- База данных: SQLite (`db_open`, `db_exec`, `db_close`)
- Многопоточность: `thread_sleep`, поддержка `std::thread`
- Опциональные импорты: `@load?` генерирует `#ifdef HAS_MODULE`
- `runtime/network.cpp`, `runtime/database.cpp`, `runtime/thread.cpp`
- Авто-определение библиотек через `pkg-config` при `--build`
- Примеры: `network.gs`, `database.gs`, `thread.gs`

### Исправлено
- `@load?` для builtin-библиотек
- `curl_write_callback` переименован для избежания конфликта
- `_parse_ident_stmt` поддерживает вызов функций без присваивания

## v0.6.0 (2026-06-01)

### Добавлено
- Файловые операции: `open()`, `read()`, `write()`, `close()`
- Математика: `sqrt()`, `sin()`, `cos()`, `tan()`, `abs()`, `pow()`
- Случайные числа: `random()`
- Время и таймеры: `time()`, `delay()`
- Столкновения (AABB): `collision.gs`
- Звук: `play_sound()`, `play_music()`, `stop_music()` через SDL_mixer
- Вызов функций без присваивания: `stop_music()`
- `BUILTIN_FUNCTIONS` — список встроенных функций
- Примеры: `math.gs`, `random.gs`, `timer.gs`, `collision.gs`, `audio.gs`

### Исправлено
- `FunCall` для встроенных функций генерирует вызов, а не `new`
- `_parse_ident_stmt` поддерживает вызов `name(args)` без присваивания

## v0.5.0 (2026-05-31)

### Добавлено
- Лямбды: `fn(x): x + 1` и `fn(): self.gold = self.gold + 1`
- `*args` — переменное число аргументов: `def sum(self, *numbers):`
- Конструкторы с параметрами: `Hero("Артур", 100)`
- Создание объектов: `new Hero()` — автоматически при `Hero()`
- Вложенные словари через `{}` с отступами
- Списки через `[]` (простые случаи)
- `screen.gs` и `menu.gs` — база для экранов

### Исправлено
- `#pragma once` только для `.h` файлов
- `_assemble` с параметром `is_header`
- `FunCall` генерирует `new ClassName()`
- IDENT в `_parse_value`

## v0.4.3 (2026-05-31)

### Добавлено
- Префиксные `++a` и `--a`
- `print()` — вывод в консоль
- `assert` — проверка условий
- `--debug` и `--debug --short` — отладка токенов и AST
- `--init [папка]` — создание нового проекта
- `--watch` — слежение за файлом и перекомпиляция
- `--help` и `--version` — справка и версия
- `-o <имя>` — имя выходного файла

### Оптимизировано
- `compiler.py`: вынесены `_debug_short`, `_debug_full`

## v0.4.2 (2026-05-31)

### Добавлено
- INDENT/DEDENT — отступы как в Python, блоки определяются пробелами
- `else if` вместо `else { if ... }` для `elif`
- Счётчик скобок — отступы подавляются внутри `{}`, `()`, `[]`

### Исправлено
- `break` и `continue` в циклах — правильные отступы
- Вложенные `if`, `while`, `for` — корректные блоки
- Отступы в сгенерированных struct (4 пробела)
- `_parse_block` переписан под INDENT/DEDENT
- Убран бесконечный цикл при DEDENT

### Удалено
- `RUNTIME_H`, `ensure_runtime`, `generate_runtime` — старый хардкод
- `_register_field`, `_check_type`, `generate_runtime_from_data` — неиспользуемые методы
- Дублирующиеся блоки `BinaryOp` в `_expr_to_cpp`
- `mainfile.gs` и лишние примеры

### Оптимизировано
- Лексер: `handle_indent` с bracket_depth
- Парсер: единый `_parse_block` через INDENT/DEDENT
- Кодген: `elif` → `else if`

## v0.4.1 (2026-05-30)

### Исправлено
- Убрано дублирование полей — классы-наследники не повторяют поля родителей
- Порядок полей: свои → родительские
- `#pragma once` во всех сгенерированных `.h` файлах
- Все зависимости подключаются через `@load` (без костылей в кодгене)

### Добавлено
- `--build -o name` — задать имя бинарника
- `--version` / `-v` — версия компилятора
- Команда `gamescript` после `pip install`
- Улучшенные сообщения об ошибках с контекстом

### Убрано
- `mainfile.gs` — заменён на `__main__.gs`
- `runtime.h` — заменён на `entity.gs` и `system.gs`

## v0.4.0 (2026-05-28)

### Добавлено
- `@load "file" like "Alias"` — алиас для импорта (`using Alias = file`)
- `@load "file" like "*"` — using namespace
- `__main__.gs` — точка входа, генерирует `int main()`
- `entity.gs` и `system.gs` — базовые классы (без хардкода)
- Перегрузка методов (разные параметры = разные функции)
- Анимации: поля `frame`, `timer`, `anim_speed`, `total_frames`
- Джойстик: класс `Joystick` с тач-управлением
- `print()` — вывод в консоль
- `assert` — проверка условий
- Логические операторы: `and`, `or`, `not`
- `elif` — цепочки условий
- Инкремент/декремент: `++`, `--`
- `None` → `nullptr`
- Массивы `[1, 2, 3]`
- Классы без родителя: `class Name:`

### Изменено
- `runtime.h` удалён — вместо него `entity.gs` и `system.gs`
- `_generate_class` объединяет `_generate_class_def` и `_generate_class_decl`
- `like` возвращён (был убран в v0.3.0)

### Исправлено
- `None` в выражениях
- `++` и `--` генерация
- `@load` в заголовочных файлах

## v0.3.0 (2026-05-28)

### Добавлено
- Автовывод типов: `int`, `float`, `str`, `bool`, `null`, `vector`, `map`
- Конструкторы с авто-инициализацией полей (`Hero() : hp(0), name("") {}`)
- Наследование полей от родительских классов
- `--build` — компиляция в машинный код через g++
- Проверка типов с предупреждениями при несоответствии
- Runtime auto-gen: `Entity` и `System` создаются на основе используемых полей
- Поддержка SDL2 через `@load "sdl2"`
- `generate_main()` — автоматическая точка входа `int main()`

### Убрано
- `~grab` — слишком сложный для v0.3.0
- `&link` — не транслировался в валидный C++
- `like` — малоиспользуемая фича

### Изменено
- `runtime.h` — генерируется из анализа всех `.gs` файлов
- `# --header` директива обязательна для заголовочных файлов

### Исправлено
- Запятые в designated initializers C++
- Отступы вложенных `if`/`while`/`for`
- Trailing comma в `dict()` и `list()`
- `@load?` не падает если файл не найден

## v0.2.0 (2026-05-27)

### Добавлено
- Автовывод типов: `100` вместо `int(100)`, `"текст"` вместо `str("текст")`
- Раздельная компиляция: `# --header` → `.h`, иначе `.cpp`
- `@load` → `#include` вместо встраивания кода
- Авто-поля классов из `self.xxx = ...` в методах
- Импорт Python-библиотек: `@load "math"` → `#include <cmath>`

### Исправлено
- Отступы вложенных `if`
- `self.` → `this->` в сгенерированном C++
