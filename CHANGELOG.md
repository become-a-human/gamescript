# Changelog

## v0.4.1 (2026-05-30)

### Исправлено
- Убрано дублирование полей — классы-наследники не повторяют поля родителей
- Порядок полей: свои → родительские
- `#pragma once` во всех сгенерированных `.h` файлах
- Все зависимости подключаются через `@load` (без костылей в кодгене)

### Добавлено
- `--build -o name` — задать имя бинарника
- `--version` / `-v` — версия компилятора
- Команда `gamescript` после `pip install`
- Улучшенные сообщения об ошибках с контекстом

### Убрано
- `mainfile.gs` — заменён на `__main__.gs`
- `runtime.h` — заменён на `entity.gs` и `system.gs`

## v0.4.0 (2026-05-28)

### Добавлено
- `@load "file" like "Alias"` — алиас для импорта (`using Alias = file`)
- `@load "file" like "*"` — using namespace
- `__main__.gs` — точка входа, генерирует `int main()`
- `entity.gs` и `system.gs` — базовые классы (без хардкода)
- Перегрузка методов (разные параметры = разные функции)
- Анимации: поля `frame`, `timer`, `anim_speed`, `total_frames`
- Джойстик: класс `Joystick` с тач-управлением
- `print()` — вывод в консоль
- `assert` — проверка условий
- Логические операторы: `and`, `or`, `not`
- `elif` — цепочки условий
- Инкремент/декремент: `++`, `--`
- `None` → `nullptr`
- Массивы `[1, 2, 3]`
- Классы без родителя: `class Name:`

### Изменено
- `runtime.h` удалён — вместо него `entity.gs` и `system.gs`
- `_generate_class` объединяет `_generate_class_def` и `_generate_class_decl`
- `like` возвращён (был убран в v0.3.0)

### Исправлено
- `None` в выражениях
- `++` и `--` генерация
- `@load` в заголовочных файлах

## v0.3.0 (2026-05-28)

### Добавлено
- Автовывод типов: `int`, `float`, `str`, `bool`, `null`, `vector`, `map`
- Конструкторы с авто-инициализацией полей (`Hero() : hp(0), name("") {}`)
- Наследование полей от родительских классов
- `--build` — компиляция в машинный код через g++
- Проверка типов с предупреждениями при несоответствии
- Runtime auto-gen: `Entity` и `System` создаются на основе используемых полей
- Поддержка SDL2 через `@load "sdl2"`
- `generate_main()` — автоматическая точка входа `int main()`

### Убрано
- `~grab` — слишком сложный для v0.3.0
- `&link` — не транслировался в валидный C++
- `like` — малоиспользуемая фича

### Изменено
- `runtime.h` — генерируется из анализа всех `.gs` файлов
- `# --header` директива обязательна для заголовочных файлов

### Исправлено
- Запятые в designated initializers C++
- Отступы вложенных `if`/`while`/`for`
- Trailing comma в `dict()` и `list()`
- `@load?` не падает если файл не найден

## v0.2.0 (2026-05-27)

### Добавлено
- Автовывод типов: `100` вместо `int(100)`, `"текст"` вместо `str("текст")`
- Раздельная компиляция: `# --header` → `.h`, иначе `.cpp`
- `@load` → `#include` вместо встраивания кода
- Авто-поля классов из `self.xxx = ...` в методах
- Импорт Python-библиотек: `@load "math"` → `#include <cmath>`

### Исправлено
- Отступы вложенных `if`
- `self.` → `this->` в сгенерированном C++

## v0.1.0 (2026-05-25)

### Добавлено
- Первый релиз
- Лексер, парсер, кодген
- Словари → C++ struct
- Классы с наследованием
- Методы с параметрами
- `if`/`else`, `while`, `for`, `continue`, `break`
- Операторы и сравнения
- Система импортов: `@load`, `~grab`, `&link`
